# Nursing Application Web App Case Study
👋 Greetings! We are excited to have you go through our Case Study. This case is designed (with the help of Replit) to understand how you would implement a React framework in this HTML/CSS/js application. While this is a full-stack study, there is an emphasis on the frontend; that doesn't mean you shouldn't flex your backend skills too. This project is ripe with opportunity and we can't wait to see what you share.

## Prerequisites
Before you begin, ensure you have Docker installed on your system. You can download it from [here](https://docs.docker.com/get-docker/). When completed, verify that you can use both Docker (run `docker -v`) and Docker Compose (`docker compose version`) locally.

## Getting Started
1. After you have Docker installed on your system, run `make build` and `make run` to build and start the containers using Docker Compose.
2. Navigate to `http://localhost:3000/` to see your running frontend web application.
2. Navigate to `http://localhost:8000/` to see your running backend API.
